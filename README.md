# The Odin Project – Odin Recipes

This project is part of _The Odin Project_ curriculum. My goal was to build a simple recipe website using only HTML and CSS.

I avoided using Flexbox and Grid in order to better understand traditional CSS layout techniques for positioning elements.

I also implemented a carousel feature using only CSS to explore advanced styling techniques without JavaScript.

## 🚀 What I Learned

- Structuring multi-page websites with HTML
- Styling layouts using basic CSS positioning
- Building interactive UI elements (carousel) without JavaScript
- Improving understanding of document flow and layout fundamentals
